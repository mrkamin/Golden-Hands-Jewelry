# 💎 Golden Hands Jewelry

> Golden Hands Jewelry is a responsive e-commerce application built with Next.js, designed for selling handmade jewelry. Users can browse products, view details, add items to their cart, and proceed to checkout. To complete a purchase, users must sign up or log in using the provided authentication forms.

<!-- Features -->

### Key Features <a name="key-features"></a>

> - The homepage displays a collection of handmade jewelry products with images, names, and prices.
> - Users can click on any product to view detailed information, including description, price, and customer reviews.
> - Users can add products to the shopping cart from the product detail page.
> - The cart page shows all selected items, their quantities, and the total cost, with options to remove individual items or clear the entire cart.
> - Users can proceed to the checkout page to review their order and confirm purchase (mock checkout).
> - Product recommendations are shown using "Related Products" and "You Might Also Like" sections.
> - A clean, responsive design ensures a smooth shopping experience across devices (mobile, tablet, desktop).
> - Users must sign up or log in to complete a purchase using the authentication forms provided.
> - Navigation links provide easy access to home, cart, checkout, and product pages.

> - All product data is displayed statically for quick access, with optional dynamic routing for product pages.

## 💻 Getting Started <a name="getting-started"></a>

## To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project you need:

- Mac or PC
- Install node.js
- Use npm or yarn as package manager.
- Have depth Understanding of nextjs, Redux and API.

### Setup

- Clone this repository to your desired folder:

```sh
 git clone git@github.com:mrkamin/Golden-Hands-Jewelry.git
```

- Navigate into the cloned folder

```sh
 cd Golden-Hands-Jewelry

```

### Install

- Install this project with:

```sh
 npm install
```

- Start the server

```sh
 npm run dev
```
